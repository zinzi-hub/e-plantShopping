# e-plantShopping

## Paradise Nursery Shopping Application

e-plantShopping is a React-based online plant shop application built as part of the final project.

This application allows users to:
- Browse house plants categorized into Air Purifying Plants and Aromatic Fragrant Plants
- View plant images, names, descriptions and costs
- Add plants to cart and see cart quantity in navbar
- Increase/decrease quantity, delete items, and view total amount
- Continue shopping and checkout

Repository name: e-plantShopping

### Technologies Used
- React
- Redux Toolkit for state management
- React Router concept
- Vite

### How to run
npm install
npm run dev
npm run preview
